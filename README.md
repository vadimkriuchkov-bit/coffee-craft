# Кофе Крафт — концепты сайта

Три концепта сайта для сети кофеен «Кофе Крафт» (Рязань). Демо для презентации, не официальный сайт.

| Вариант | Папка | Идея |
|---|---|---|
| 01 Поезд | `train/` | Игрушечный паровоз из «Аркады» везёт кофе через весь сайт. Скролл = поездка по станциям |
| 02 Раф-лаборатория | `raf/` | 3D-стакан наполняется на глазах, конструктор рафа с ценой, тест «Какой ты раф», карта лояльности |
| 03 Музей десертов | `museum/` | Тёмный зал с прожекторами, десерты как экспонаты, схема 6 кофеен в стиле метро с живым статусом |

## Стек
Vite · Three.js · GSAP (ScrollTrigger) · Lenis. Без фреймворков, всё 3D собрано кодом.

## Запуск
```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/ — заливается на Netlify / Vercel / GitHub Pages
```
Открыть в браузере без установки: `https://stackblitz.com/github/<владелец>/coffee-craft`

## Данные
`src/data.js` — адреса, телефоны, часы, меню. Собраны из открытых источников (2ГИС, Zoon, Restaurant Guru, ВК) в ноябре 2026.
Перед запуском сверить цены с электронным меню и часы работы Чкалова, 18 и Быстрецкой, 18 к3.
